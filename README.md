### 🧭 Sobre mim

Sou Anthony, estudante de Engenharia de Software e Técnico em Informática, com foco em desenvolvimento de software e interesse especial em **backend, cloud e observabilidade**.

Tenho experiência prática no desenvolvimento de aplicações web utilizando JavaScript, Node.js, HTML, CSS e Bootstrap, além de conhecimentos em Java, Spring Boot, APIs REST, bancos de dados e Git/GitHub.

Também possuo contato prático com tecnologias de infraestrutura e observabilidade, incluindo AWS, Docker, Kubernetes, Grafana, Prometheus e Zabbix. Essa experiência me permite enxergar o desenvolvimento além do código, considerando também disponibilidade, desempenho, monitoramento e manutenção das aplicações.

Gosto de aprender na prática, transformar problemas em soluções e entender como diferentes tecnologias se conectam para construir sistemas mais organizados, confiáveis e fáceis de manter.

Sou proativo, comunicativo e gosto de trabalhar em equipe. Atualmente busco uma oportunidade de estágio ou posição júnior onde possa aplicar meus conhecimentos, aprender com profissionais experientes e continuar evoluindo na área de Engenharia de Software.
