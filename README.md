# Anthony Freitas Borges

Estudante de Engenharia de Software na PUC Minas, em Belo Horizonte. Atuo com observabilidade e estou aprofundando meus estudos em backend, infraestrutura e DevOps.

Minha experiência começou no Service Desk e no monitoramento de ambientes. Hoje, trabalho com dashboards, métricas, logs e alertas usando Grafana, Zabbix, Prometheus e AWS CloudWatch. Gosto de investigar falhas e transformar verificações manuais em automações que ajudem na operação.

Nos projetos de desenvolvimento, uso Java com Spring Boot, Node.js, bancos relacionais e Docker. Meu foco é entender o caminho completo de uma aplicação: da API e dos dados à execução e ao monitoramento.

## O que estou construindo

- **[Sistema para barbearia](https://github.com/anthonyfreitasborges/Barbearia):** projeto com Spring Boot, React e MariaDB, com ambiente organizado em Docker Compose. Estou desenvolvendo as regras de negócio e a separação entre controllers, services e repositories.
- **Monitoramento de jornadas de login:** estudos com Playwright e Zabbix Browser Monitoring para verificar se uma aplicação permite que o usuário entre e conclua um fluxo, além de responder a uma requisição.
- **Automação de monitoramento:** scripts e alertas para acompanhar recursos de infraestrutura e reduzir consultas e verificações manuais.

## Tecnologias no meu dia a dia

**Observabilidade:** Grafana, Zabbix, Prometheus e AWS CloudWatch.  
**Desenvolvimento e ambiente:** Java, Spring Boot, Node.js, SQL, Docker, Git e Linux.

Busco oportunidades de estágio em infraestrutura, DevOps e observabilidade, com espaço para desenvolver automações e trabalhar próximo das aplicações.
